# 1071. Greatest Common Divisor of Strings

For two strings `s` and `t`, we say " `t` divides `s` " if and only if `s = t + t + t + ... + t + t` (i.e., `t` is concatenated with itself one or more times).

Given two strings `str1` and `str2`, return *the largest string* `x` *such that* `x` *divides both* `str1` *and* `str2`.

**Example 1:**

```
Input: str1 = "ABCABC", str2 = "ABC"
Output: "ABC"
```

**Example 2:**

```
Input: str1 = "ABABAB", str2 = "ABAB"
Output: "AB"
```

**Example 3:**

```
Input: str1 = "LEET", str2 = "CODE"
Output: ""
```

**Constraints:**

- `1 <= str1.length, str2.length <= 1000`
- `str1` and `str2` consist of English uppercase letters.


```ad-tip
title: hint
collapse:close
The greatest common divisor must be a prefix of each string, so we can try all prefixes.
```

## Approach

### GCD

xem hàm [[GCD]]

**?Tại sao lại check cộng chuỗi**

Nếu 2 str có common divisor (ước chung) thì concat kiểu str1.concat(str2) hay str2.concat(str1) đều ra cùng kết quả

```
str1 + str2 = (base * k) + (base * m) = base * (k + m)
str2 + str1 = (base * m) + (base * k) = base * (m + k)
```

=> Bước đầu kiểm tra `str1 + str2 == str2 + str1`, nếu khác chứng tỏ khác pattern

ví dụ:

`abcabc` + `abcabcabc` ->true
`aaa` + `aab` != `aab` + `aaa` ->false

**? Tại sao lại là gcd của length**

Ở công thức trên, cho qua len()
-> len(base) là ước chung của len(str1) và len(str2)

Tìm base dài nhất -> gcd len

```cpp
string gcdOfStrings(string str1, string str2) {
	if (str1 + str2 != str2 + str1){
		return "";
	}
	return str1.substr(0, gcd(str1.size(), str2.size()));
}
```

```python
def gcdOfStrings(self, str1: str, str2: str) -> str:
	if str1 + str2 != str2 + str1:
		return ""
	return str1[0:gcd(len(str1), len(str2))]
```
