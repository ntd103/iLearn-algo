# Solutions - Lecture Notes

Folder này chứa **giải pháp chi tiết** và **lecture notes** cho các bài toán.

## Mục đích

Ghi chép như **bài giảng** (lecture):
- Giải thích chi tiết approach
- Multiple solutions (nếu có)
- Phân tích complexity
- Tips & tricks
- Common mistakes
- Related problems

## Format

Mỗi file `.md` là 1 bài lecture đầy đủ:

```markdown
# Problem Name

## Problem Statement
[Đề bài đầy đủ]

## Approach 1: Brute Force
[Giải thích cách làm đơn giản nhất]

### Code
\```cpp
// code
\```

### Complexity
- Time: O(n²)
- Space: O(1)

## Approach 2: Optimized
[Cách tối ưu]

### Code
\```cpp
// optimized code
\```

### Complexity
- Time: O(n)
- Space: O(n)

## Key Insights
- Insight 1
- Insight 2

## Common Mistakes
- Mistake 1
- Mistake 2

## Related Problems
- Problem A
- Problem B
```
