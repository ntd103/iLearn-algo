# 2566. Maximum Difference by Remapping a Digit

You are given an integer `num`. You know that Bob will sneakily **remap** one of the `10` possible digits (`0` to `9`) to another digit.

Return *the difference between the maximum and minimum values Bob can make by remapping **exactly** **one** digit in* `num`.

**Notes:**

- When Bob remaps a digit d1  to another digit d2, Bob replaces all occurrences of `d1`  in `num`  with `d2`.
- Bob can remap a digit to itself, in which case `num` does not change.
- Bob can remap different digits for obtaining minimum and maximum values respectively.
- The resulting number after remapping can contain leading zeroes.

**Example 1:**

```
Input: num = 11891
Output: 99009
Explanation: 
To achieve the maximum value, Bob can remap the digit 1 to the digit 9 to yield 99899.
To achieve the minimum value, Bob can remap the digit 1 to the digit 0, yielding 890.
The difference between these two numbers is 99009.
```

**Example 2:**

```
Input: num = 90
Output: 99
Explanation:
The maximum value that can be returned by the function is 99 (if 0 is replaced by 9) and the minimum value that can be returned by the function is 0 (if 9 is replaced by 0).
Thus, we return 99.
```

**Constraints:**

- `1 <= num <= 10<sup>8</sup>`

# MyNote

Tìm MAX value: Remap một chữ số để được số lớn nhất
Tìm MIN value: Remap một chữ số để được số nhỏ nhất
Trả về MAX - MIN

**Approach**
- Để có MAX value:
	- Tìm chữ số đầu tiên từ trái sang không phải là 9
	- Remap chữ số đó thành 9
	- Nếu tất cả đều là 9 → không cần thay đổi gì (giữ nguyên)
- Để có MIN value:
	- Tìm chữ số đầu tiên từ trái sang không phải là 0
	- Remap chữ số đó thành 0
	- Lưu ý: Leading zeros được phép (vd: "0234" → 234)

```cpp
class Solution {
public:
    int minMaxDifference(int num) {
        string s = to_string(num);
        
        string maxStr = s;
        for (char& c : maxStr) {
            if (c != '9') {
                char target = c;
                for (char& ch : maxStr) {
                    if (ch == target) ch = '9';
                }
                break;
            }
        }
        
        string minStr = s;
        for (char& c : minStr) {
            if (c != '0') {
                char target = c;
                for (char& ch : minStr) {
                    if (ch == target) ch = '0';
                }
                break;
            }
        }
        
        return stoi(maxStr) - stoi(minStr);
    }
};
```
