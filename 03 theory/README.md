# Theory - Học Lý Thuyết

Folder này dùng để học và ghi chép **lý thuyết** về:
- Data Structures (Cấu trúc dữ liệu)
- Algorithms (Thuật toán)
- Concepts & Patterns (Khái niệm & Pattern)

## Cấu trúc

```
theory/
├── data-structures/
│   ├── arrays.md
│   ├── linked-list.md
│   ├── trees.md
│   ├── graphs.md
│   └── ...
│
├── algorithms/
│   ├── sorting.md
│   ├── searching.md
│   ├── dynamic-programming.md
│   ├── graph-algorithms.md
│   └── ...
│
└── concepts/
    ├── time-complexity.md
    ├── space-complexity.md
    ├── recursion.md
    └── ...
```

## Cách dùng

1. **Học concept mới** → Tạo file `.md` trong folder tương ứng
2. **Viết lý thuyết** → Giải thích, vẽ diagram, note ví dụ
3. **Code minh họa** → Thêm code snippet để hiểu rõ

## Example

**theory/algorithms/binary-search.md**:
```markdown
# Binary Search

## Concept
Tìm kiếm nhị phân là thuật toán...

## Complexity
- Time: O(log n)
- Space: O(1)

## Implementation
\```cpp
int binarySearch(vector<int>& arr, int target) {
    // code here
}
\```

## When to use
- Mảng đã sorted
- Cần tìm kiếm nhanh
```

**Mục đích**: Học sâu, hiểu rõ concept, không vội code problem.
